# Analytics API（服務藍圖）

> **類型**：藍圖（服務）
> **焦點**：這個服務對系統其他部分的承諾，以及它依賴什麼。
> **限制**：只寫現況。不寫檔案結構、函式庫或實作（看程式碼庫）。不寫欄位層級的形狀（看合約檔）。不寫理由（看[決策日誌](safechord.safezone.decisions.md)）。不寫沿革（看 [changelog](safechord.safezone.changelog.md)）。

## 1. 職責

*   **角色**：讀取者 / 聚合器
*   **核心目標**：作為系統的讀取端。以全國、城市或區域為層級，聚合一段時間窗內已儲存的病例數，並替資料庫擋下重複的相同查詢。

## 2. 需求

每條需求都是系統其他部分會依賴的承諾。守住某條需求的測試會帶上它的 ID。所有服務共用的需求放在[服務標準](safechord.safezone.service.standards.md)，這裡不重複。

### API-R1：查詢回傳時間窗內的病例數
對於請求的日期與時間窗長度，API 必須回傳以該日期為結尾（含兩端）的那幾天內已儲存病例數的總和，範圍可以是全國、單一城市，或某城市的單一區域。

#### 情境：城市的七日查詢
- GIVEN 某城市十天內的已儲存病例數
- WHEN 查詢該城市以其中最後一天為結尾的七天
- THEN 結果是該城市這七天病例數的總和

### API-R2：比率查詢回傳每萬人病例數
對城市或區域請求比率時，API 必須回傳時間窗內該城市或區域的每萬人病例數，取代病例總數。

#### 情境：區域的比率
- GIVEN 一個人口已知、時間窗內有病例的區域
- WHEN 對它請求比率
- THEN 結果是病例數除以人口再乘以 10,000

### API-R3：沒有病例的時間窗回傳零
請求的時間窗與地點沒有已儲存的病例時，API 必須回傳零，而不是錯誤。

#### 情境：時間窗內沒有資料
- GIVEN 一個有效但時間窗內沒有已儲存病例的城市
- WHEN 查詢它
- THEN 結果是零

### API-R4：未知的地點被拒絕
查詢指定了不存在的城市，或不屬於該城市的區域時，API 必須拒絕。

#### 情境：別的城市的區域
- GIVEN 一個存在於另一個城市底下的區域
- WHEN 用錯誤的城市查詢它
- THEN 查詢被判定無效而拒絕

### API-R5：重複的查詢由快取回應
快取版本不變時，API 必須不查資料庫就回應它已經回應過的查詢。

#### 情境：相同的查詢兩次
- GIVEN 一個已經被回應過一次的查詢
- WHEN 相同的查詢在同一個快取版本下再次到達
- THEN 不查資料庫就回傳答案

### API-R6：新的快取版本讓舊答案退場
快取版本改變後，API 必須在一個輪詢間隔內停止提供舊版本下快取的答案。

#### 情境：資料集被更新
- GIVEN 一個在某快取版本下快取的答案
- WHEN 快取版本改變且經過一個輪詢間隔
- THEN 相同的查詢會再次由資料庫回應

### API-R7：每個答案都標明是否來自快取
每個聚合回應都必須在回應標頭中標明，它是由快取提供的還是即時計算的。

#### 情境：第一次與第二次請求
- GIVEN 一個尚未快取的查詢
- WHEN 它被送出兩次
- THEN 第一個回應標為即時計算，第二個標為由快取提供

### API-R8：同時發生的相同 miss 只花一次查詢
在單一 instance 內，同時到達且都沒命中快取的相同查詢，必須只造成一次資料庫查詢。

#### 情境：冷鍵上的瞬間流量
- GIVEN 一個尚未快取的查詢
- WHEN 許多相同的請求同時到達同一個 instance
- THEN 資料庫只被查詢一次

## 3. 依賴

| Channel | 方向 | 合約 | 另外假設 |
| :--- | :--- | :--- | :--- |
| 查詢 API | 提供 | 尚無語言中立的合約。以 `SafeZone/utils/pydantic_model/` 為準，dashboard 以手抄方式對應；尚無票。 | 無。 |
| 病例表 | 讀取 | 尚無語言中立的合約。以 `SafeZone/utils/db/schema.py` 為準；SQL 匯出追蹤於 SafeZone#70。 | 每個日期、城市、區域一列。 |
| 行政區與人口資料表 | 讀取 | 同病例表。 | API 啟動時資料已齊。之後新增的資料要重啟才看得到。 |
| 快取版本鍵 | 讀取 | 沒有合約檔。鍵名在 relay CLI 與本服務各寫一份；尚無票。 | 每次有新增資料的模擬觸發之後，它的值都會改變。 |
| 回應快取 | 讀取 / 寫入 | 本服務私有。 | 無。 |
