# Dashboard v2（服務藍圖）

> **類型**：藍圖（服務）
> **焦點**：此服務對系統其他部分的承諾，及其所依賴的項目。
> **限制**：僅描述現狀。不含檔案結構、函式庫或實作
> （程式碼）。不含欄位層級定義（合約檔案）。不含理由
> （[決策紀錄](safechord.safezone.decisions.md)）。不含歷史
> （[變更紀錄](https://github.com/SafeChord/SafeZone/blob/main/CHANGELOG.md)）。

## 1. 責任

*   **角色**：視覺化（瀏覽器客戶端）
*   **核心目標**：向觀看者顯示案件位置，以及跨城市與地區的比較，使用模擬目前所在的日期而非觀看者自己的時鐘。

## 2. 需求

每項需求都是系統其他部分所依賴的承諾。驗證某項需求的測試會帶有其 ID。所有服務共通的需求收錄於[服務標準](safechord.safezone.service.standards.md)，此處不重複列出。

### DSH-R1：頁面跟隨系統日期
儀表板必須顯示時間伺服器提供的系統日期，並且必須在該日期變更後的一個輪詢間隔內，為新日期重新載入每個圖表。

#### 情境：模擬時間推進
- GIVEN 儀表板顯示某個系統日期的圖表
- WHEN 時間伺服器的系統日期推進
- THEN 在一個輪詢間隔內，儀表板顯示新日期及其圖表

### DSH-R2：觀看者可從城市向下鑽研至地區
在地圖上選取城市後，必須顯示該城市的地區，每個地區各有其所選時間區間的圖表。

#### 情境：選取城市
- GIVEN 全國地圖
- WHEN 觀看者選取一個城市
- THEN 地圖顯示該城市的地區，每個地區各附圖表

### DSH-R3：觀看者可選擇時間區間與指標
儀表板必須讓觀看者選擇時間區間的長度，並將每個地圖與圖表的圖示在案件數與每萬人案件數之間切換。

#### 情境：切換至比率
- GIVEN 圖表以案件數顯示
- WHEN 觀看者切換至比率
- THEN 每個地圖與圖表的圖示均顯示每萬人案件數

### DSH-R4：城市排名始終涵蓋七天
城市排名必須涵蓋到系統日期為止的七天，無論觀看者選取了何種時間區間。

#### 情境：觀看者選取 30 天時間區間
- GIVEN 觀看者選取 30 天時間區間
- WHEN 排名顯示時
- THEN 仍依到系統日期為止的七天對城市進行排名

### DSH-R5：依賴失敗不應中斷頁面
當 analytics API 或時間伺服器失敗時，儀表板必須保持可用，並告知觀看者資料無法取得。

#### 情境：analytics API 回傳錯誤
- GIVEN analytics API 回應錯誤
- WHEN 儀表板載入圖表時
- THEN 頁面仍能回應觀看者
- AND 顯示資料無法載入

### DSH-R6：每個請求皆啟動追蹤
儀表板發送的每個請求必須攜帶新建立的追蹤 ID。此項將 STD-R1 套用至追蹤起始點。

#### 情境：兩個請求
- GIVEN 儀表板發送的兩個請求
- WHEN 比較兩者的追蹤 ID
- THEN 每個請求皆攜帶追蹤 ID，且兩者不同

### DSH-R7：同一映像可在所有環境中執行
儀表板映像不得包含環境特定的路由。同一映像必須在所有環境中不經修改即可執行，路由於部署時提供。

#### 情境：同一映像，兩種環境
- GIVEN 一個已建置的映像
- WHEN 以不同的路由分別部署至本機與叢集
- THEN 無須重新建置即可在兩者中提供儀表板服務

## 3. 依賴

| 管道 | 方向 | 合約 | 附加假定 |
| :--- | :--- | :--- | :--- |
| Analytics query API | 呼叫 | 尚無語言中立合約。`SafeZone/utils/pydantic_model/` 為權威來源，此服務以手動方式對應；尚無 ticket。 | 無。 |
| Time server API | 呼叫 | 與 analytics query API 相同。 | 無。 |
| 行政邊界 | 讀取 | `SafeZone/utils/geo_data/boundaries/` | 邊界檔案中的城市與地區名稱等同於 analytics API 接受的名稱。檢查項目記錄於 SafeZone#55。 |
